# 📂 File System Manager

A lightweight simulation of an operating system–style file system built in Python.  
The project demonstrates **block allocation**, **directory hierarchy**, and **file metadata management** using custom data structures and `.bin` file storage.  

## 🚀 Features
- Create, read, write, and delete files  
- Create and navigate directories  
- Allocate and free disk blocks dynamically  
- Maintain a file table (similar to inodes) for metadata  
- Basic error handling (out-of-space, invalid paths, etc.)  

## 🏗️ Tech Stack
- Python (core logic, binary file handling)  
- CLI (menu-driven interface)  
- Optional: PyQt Designer / Tkinter GUI layer for visualization  

## 📖 Educational Purpose
Designed to demonstrate how file systems work under the hood: allocation tables, metadata, and hierarchical storage — without needing a real OS kernel.
